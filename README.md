## 下载与安装

当前支持 **Apple Silicon（M 系列芯片）Mac，macOS 15 或更新版本**。不支持 Intel Mac 或 Windows。不同语言的可用性取决于系统语言资源。

1. 从上方下载页选择 `ShengQiao-0.1.0-preview.1-macOS-arm64.dmg`。
2. 打开 DMG，将 `LinguaRelay.app` 拖到「Applications／应用程序」。
3. 从「应用程序」中打开「声桥 LinguaRelay」。也可下载 ZIP，解压后将应用移入「应用程序」。
4. 首次使用按系统提示下载所需语言资源，并允许对应的语音识别、麦克风或系统音频权限。

**此预览版尚未使用 Apple Developer ID 签名，也未经过 Apple 公证。** macOS 可能提示无法验证开发者或无法检查恶意软件。如果你确认下载来源为本仓库，可在尝试打开后进入「系统设置 → 隐私与安全性」，查看是否提供「仍要打开」；具体提示以系统为准。参考 [Apple 官方打开说明](https://support.apple.com/zh-cn/102445)。

下载页同时提供 `SHA256SUMS.txt`。在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt` 可核对两个安装包；若只下载了其中一个，另一个会显示缺少文件。校验和用于核对文件完整性，不替代开发者签名与公证。

GitHub 自动提供的 `Source code (zip/tar.gz)` 只包含这个下载仓库的说明文件，**不是安装包，也不包含声桥应用源码**。

## 可以做什么

✅ **实时翻译电脑声音**：会议、网课、视频等正在播放的声音，可识别并翻译为字幕。

✅ **麦克风转写与翻译**：选择麦克风输入，点击开始后采集。支持仅转写。

✅ **双语悬浮字幕**：同时显示原文和译文，可移动窗口、调整大小、字号和背景透明度。

✅ **滚动字幕与回看**：保留本次会话内容，上滚回看时暂停跟随，点击「回到实时」继续。

✅ **音频文件和文本翻译**：导入系统可解码的音频文件，或粘贴文本进行翻译。

✅ **历史记录与导出**：在本机保存会话，支持搜索和导出 TXT、Markdown、双语 SRT、JSON。

✅ **译文朗读**：使用系统声音朗读译文。是否能让会议对方听见，取决于会议软件的音频路由；本版没有内置虚拟声卡。

## 第一次使用

1. 选择原文与译文语言，例如「英语 → 简体中文」。
2. 看视频或线上会议时选择「系统声音」；现场讲话选择「麦克风」。
3. 点击「开始翻译」，按系统提示完成权限授权。系统要求退出重开时，按提示操作。
4. 先播放一段测试语音，确认声音输入、语言资源和字幕正常，再用于正式场景。
5. 点击「浮动字幕」，可把字幕窗口放到视频旁；结束后点击「停止」。

快捷键：`⌘N` 新会话、`⌘,` 设置、`⌘⇧R` 开始/停止、`⌘⇧F` 浮动字幕。

## 数据与隐私

- 应用启动时不会自动录音；点击开始后才采集所选输入。
- 使用 Apple 设备端语音识别，不支持本地识别的语言会报错，不回退到云端识别。
- 使用 Apple Translation 翻译；首次使用可能需要联网下载系统语言资源。
- 英文标点模型随应用打包，在本机处理转写文字。
- 原始音频在内存中处理，不保存录音文件；系统声音模式不保存屏幕画面。
- 会话文字以未加密 JSON 保存在 `~/Library/Application Support/LinguaRelay/`。移除记录会移入该目录的 `Trash/`，不会立即彻底删除。
- 无需声桥账号或第三方 API Key。当前应用没有自建后端、云同步或应用内统计服务。

## 预览版的已知限制

- 连续讲话时仍可能出现残句、错误拆句或过长字幕；识别错词也会影响翻译。不能承诺逐字无遗漏或准确率。
- 首次冷启动可能漏掉开头，建议先用测试语音预热。
- 尚未完成长会议稳定性与端到端延迟基准测试；本次发布包没有在另一台全新 Mac 上完成安装验收。
- SRT 时间在部分情形下为估算值，不是逐帧校准字幕。
- 尚未支持自动双语识别、应用内麦克风设备切换、虚拟声卡、云同步、会议摘要或第三方翻译 API。
- 本版使用临时签名，升级后 macOS 可能要求重新授权。

## 第三方组件

声桥使用 sherpa-onnx、ONNX Runtime 和 Edge-Punct-Casing 英文标点模型。组件来源与许可随应用放在 `Contents/Resources/ThirdParty/`，也可查阅本仓库 [ThirdParty](ThirdParty)。第三方许可仅适用于相应组件，不代表声桥应用源码开放。
